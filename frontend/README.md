# Frontend — Disciplina PRO

Aplicação React/Vite da plataforma Disciplina PRO e de seus programas.

Consulte o [README principal](../README.md) para visão do produto, arquitetura, rotas e fluxo de contribuição.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm test
npm run build
```

Os protótipos HTML presentes neste diretório são referências funcionais e visuais. A aplicação ativa está em `src/`.
